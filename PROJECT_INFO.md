## 🚀 Quick Start

1. **Extract the archive**:
   ```bash
   tar -xzf dailydine-complete.tar.gz
   cd dailydine
   ```

2. **Run setup script**:
   ```bash
   chmod +x setup.sh
   ./setup.sh
   ```

3. **Start development**:
   ```bash
   npm run dev
   ```

4. **Open**: http://localhost:3000
